# Library Management System

A web-based Library Management System designed to streamline library operations, track book inventories, and manage user borrowings efficiently. 

## 🚀 Features
* **User Authentication:** Secure login and session management.
* **Core Operations:** Manage books, authors, categories, and student records.
* **Admin & Librarian CRUD:** Complete ability to Create, Read, Update, and Delete records for books, authors, users, and borrowing transactions.
* **Database Driven:** Powered by a clean MySQL relational database structure.
* **Responsive UI:** Clean interface built with custom styling.

## 🛠️ Tech Stack
* **Backend:** PHP
* **Database:** MySQL
* **Frontend:** HTML, CSS, JavaScript
